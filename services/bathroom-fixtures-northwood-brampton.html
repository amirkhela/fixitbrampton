How much does it cost to install a toilet?

Straight swap on a working flange $160–220 including wax ring and sealant. Flange repair adds $60–120. New toilet supply line, new angle stop, and caulking all included.

Can you install a new vanity?

Yes — standard-size swaps $240–340 labour. Vanity top install with sink cutout $300–520 depending on counter material. We coordinate with the plumbing so it's one visit.

Do you replace bathroom exhaust fans?

Yes — swap-in replacement using the existing duct run. New ducting through the attic is a bigger job, we'll quote on-site.
